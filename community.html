// néron community

100 % local. Open source. Une commande.

Néron Community est la version gratuite et open source de Néron : elle tourne entièrement sur votre machine, sous licence MIT. C'est la génération précédente de Néron — le développement actif se poursuit ailleurs, les mises à jour de cette version sont donc limitées.

// fonctionnalités

Tout ce dont vous avez besoin,
rien de superflu.

Une architecture modulaire pensée pour tourner sur du matériel humble, avec une expérience complète.

  • 🧠

    LLM Local via Ollama

    Llama, Mistral, Gemma — choisissez votre modèle. Aucune API externe, aucune latence réseau, zéro frais.

  • 🎙️

    Speech-to-Text Whisper (à venir)

    Transcription vocale locale avec Whisper (modèle open source, aucune donnée envoyée). Tourne entièrement sur votre machine.

  • 🔊

    Text-to-Speech natif (à venir)

    Réponses vocales avec eSpeak. Néron vous répond à voix haute, sans connexion internet.

  • 💾

    Mémoire persistante

    SQLite embarqué. Néron se souvient de vos conversations, préférences et contexte au fil du temps.

  • 📱

    Interface Telegram

    Discutez avec Néron depuis votre téléphone via Telegram. L'IA, la mémoire et vos données tournent chez vous ; Telegram reste un service tiers, par lequel vos messages transitent pour vous atteindre.

  • ⚙️

    Service systemd

    Démarre automatiquement au boot, redémarre en cas de crash. Gérez tout avec make start/stop.

// architecture

Un seul processus.
Plusieurs agents.

Cette version de Néron tourne comme un seul processus Python léger. Chaque fonctionnalité est un agent indépendant.

  • FastAPI Core — Orchestrateur central exposé sur :8000. Point d'entrée unique.

  • Agents modulaires — LLM, STT, TTS, Mémoire, Telegram s'activent selon la config.

  • Ollama natif — Communication directe HTTP avec Ollama local. Aucun intermédiaire.

  • SQLite embarqué — Base de données locale, zéro dépendance externe.

Parlez-lui.
Il se souvient.

  • 💬

    Conversations naturelles

    Posez des questions, donnez des instructions. Néron comprend le contexte et répond naturellement.

    Néron se souvient de vos échanges passés. Le contexte persiste entre les sessions.
